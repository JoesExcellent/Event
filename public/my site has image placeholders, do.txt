my site has image placeholders, do I use the CSS Style sheet or the html pages

Use the HTML pages to replace the placeholders with real images.

Right now you have placeholder sections like:

<div class="hero-image-placeholder">
    Homepage Hero Photograph Placeholder
</div>

Replace them with:

<img
    src="images/joe.png"
    alt="The Excellent Management Company Recruitment Team"
    class="hero-image"
>

Then add this ONCE to your style.css:

.hero-image {
    width: 100%;
    height: 260px;
    object-fit: cover;
    border-radius: 18px;
    margin: 30px 0;
    display: block;
}

For smaller card images:

Replace:

<div class="card-image-placeholder">
    Candidate Photograph Placeholder
</div>

with:

<img
    src="images/joe.png"
    alt="Candidate profile photograph"
    class="card-image"
>

Then add this ONCE to style.css:

.card-image {
    width: 100%;
    height: 220px;
    object-fit: cover;
    border-radius: 14px;
    margin: 20px 0;
    display: block;
}

So the rule is:

HTML = tells the page WHICH image to use
CSS = controls HOW the image looks

That separation is the professional approach.
